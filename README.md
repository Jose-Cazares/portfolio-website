# portfolio-website

A responsive portfolio website built with HTML and CSS.

> **Note:** All projects and personal information in this site are fictional
> and used for demonstration purposes only.

## Features

- Responsive layout for desktop, tablet, and mobile
- Hero, projects, about, services, and contact sections
- Hover effects on buttons

## Built with

- HTML5
- CSS3 (Flexbox, media queries)

## Getting started

1. Clone the repository:
```bash
   git clone https://github.com/Jose-Cazares/portfolio-website.git
```
2. Open the folder and double-click `index.html`, or use the
   Live Server extension in VS Code.

## Project structure
